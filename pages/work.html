Contract Intelligence Service

Sep 2026 Code on GitHub

An agentic clause-extraction service over CUAD (510 contracts, 13,101 labeled clauses). Hybrid retrieval feeds a tool-calling agent with verbatim grounding, and evals gate CI. Ablating retrieval showed that recall misleads when an agent consumes the results.

What I built
  • Hybrid Postgres full-text search + pgvector retrieval with a cross-encoder reranker
  • A tool-calling agent with Pydantic outputs
  • Verbatim grounding of extracted clauses
  • 30 deterministic rules
  • OpenTelemetry tracing
  • CI-gated evals
What the evaluation showed

I ablated retrieval over 84 cases. Skipping the cross-encoder reranker kept recall@20 at 0.917 with 360× lower latency, yet cut end-to-end span F1 by 0.074, because the agent depends on rank order. Judged by recall alone, the reranker looked removable; judged by what the agent extracted, it was not.

Consumer Credit PD Modeling & Vintage Backtesting

Aug 2026 Code on GitHub

A champion–challenger probability-of-default framework on 1.3M+ LendingClub loans, tested out of time on later vintages. The repo includes an eight-section model governance document, an interactive HTML dashboard, and a README written as a case study.

What I built
  • An origination-time PySpark feature pipeline from 2.26M raw records
  • Every post-origination field excluded to control target leakage; caught FICO fields missing from the extract
  • An out-of-time split: train 2007–2015, test 2016–2018
  • A 3-feature logistic regression champion and a 37-feature LightGBM challenger
  • An eight-section model governance document and an interactive HTML dashboard
What the evaluation showed

Both models showed near-identical calibration drift, which pointed at the vintages, not the models. 90.5% of 2018 loans were still unresolved (label censoring), yet age-matched default curves showed 2018 loans genuinely defaulting slower.

small-inference

Oct 2026 Code on GitHub

A single-GPU LLM serving engine built from scratch: a paged KV cache, Triton paged-attention kernels, and continuous batching with chunked prefill.

What I built
  • A paged KV cache
  • Triton paged-attention kernels
  • Continuous batching with chunked prefill
  • An INT8 KV cache with per-channel K scaling
  • 331 correctness tests, including bit-identical logits vs Hugging Face
What the evaluation showed

The INT8 KV cache with per-channel K scaling holds perplexity within 0.56% of bf16 while lifting throughput 22%.

ResearchLineage (team project)

Apr 2026 Code on GitHub

A team project on citation-lineage prediction. My part was evaluation: a reproducible harness for the project's fine-tuned Qwen 2.5-7B, a benchmark against Gemini 2.5 Flash, and the gates a model must pass before promotion.

What I built
  • A reproducible evaluation harness: strict/soft match, MRR, secondary-influence F1, and a 5-dimension LLM-as-judge
  • A benchmark against Gemini 2.5 Flash on 101 held-out samples
  • Promotion gates on strict accuracy, judge score, and slice disparity
What the evaluation showed

On 101 held-out samples, the fine-tuned Qwen 2.5-7B scored 0.736 composite against 0.785 for Gemini 2.5 Flash.
