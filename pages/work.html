Consumer Credit PD Modeling & Vintage Backtesting

A champion–challenger probability-of-default framework on 1.3M+ LendingClub loans with an out-of-time split (train 2007–2015, test 2016–2018). The repo includes an eight-section model governance document, an interactive HTML dashboard, and a README written as a case study.

AUC 0.681 → 0.705, KS 0.266 → 0.299 — a 37-feature LightGBM challenger over a 3-feature logistic champion
2.26M raw records into an origination-time PySpark pipeline, excluding every post-origination field to control target leakage; caught FICO fields missing from the extract
90.5% of 2018 loans were still unresolved (label censoring), yet age-matched default curves showed 2018 loans genuinely defaulting slower — the shared calibration drift came from the vintages, not the models
