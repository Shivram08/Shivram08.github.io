Choices I can walk you through

Four calls from recent work, and the evidence behind each.

  • Judge retrieval by what the agent does with it.

    In an 84-case ablation of the clause-extraction service, dropping the cross-encoder reranker kept recall@20 at 0.917 with 360× lower latency. But end-to-end span F1 fell by 0.074, because the agent depends on rank order.

    Contract Intelligence case study

  • Remove retrieval when the sources fit.

    At FM Global I benchmarked the RAG layer against long-context ingestion of each report's source documents. Every report's sources fit the model window, so removing retrieval eliminated retrieval misses and a component to maintain.

    FM Global on the experience page

  • Set the cutoff from the cost of each mistake.

    With a 93/5/2 class imbalance, I used SMOTE and PR-AUC-driven threshold selection. Cutoffs came from the relative cost of missing a high-loss building versus over-flagging one, instead of defaulting to 0.5.

    FM Global on the experience page

  • Check whether drift belongs to the model or the data.

    Both credit models showed near-identical calibration drift. 90.5% of 2018 loans were still unresolved (label censoring), yet age-matched default curves showed 2018 loans genuinely defaulting slower.

    Credit PD case study
